# 🏥Hospital management System

Welcome to the Clinic Management System! This is a lightweight, Core Java application designed to handle patient registration, doctor scheduling, and prescription tracking through a fast, interactive command-line interface. 

This `README.md` file is located at the root level of the repository[cite: 9].

## ✨ Features
* **👨‍⚕️ Doctor & Patient Registries:** Easily enroll new patients and doctors with unique ID validation.
* **📅 Smart Scheduling:** Book appointments with built-in conflict detection to prevent double-booking.
* **💊 Prescription Management:** Finalize appointments by attaching medical prescriptions and dosage notes directly to the visit record.
* **📂 Medical History:** Pull complete historical visit records for any patient instantly.
* **❌ Cancellation Handling:** Safely cancel appointments and free up schedule slots.

## ⚙️ Prerequisites & Environment Setup
This project is built using standard Core Java. It requires no external libraries, frameworks, or complicated environment configurations[cite: 9]. 

* **Java Development Kit (JDK):** Ensure you have JDK 8 or higher installed.
* **Terminal Access:** The application must be fully executed via the command line (e.g., Windows CMD, PowerShell, or Ubuntu Terminal). Submissions that cannot be run from a terminal environment without a GUI-based setup will be penalized[cite: 9].
